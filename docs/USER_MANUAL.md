# 用户操作手册

> 适用于业务人员（运营/编辑/审核员/发布员/管理员）
> 版本：V1.0 | 日期：2026-09-02

## 1. 系统简介

Temu 自动选品与上品工作流是一个**自动处理 + 两次人工把关**的系统：

```
候选商品 → 自动评分 → 一审 → 资料生成 → 二审 → 自动发布 → Temu
```

### 1.1 角色与权限

| 角色 | 主要职责 | 可做操作 |
|---|---|---|
| **系统管理员** | 配置、用户管理 | 全部 |
| **选品运营** | 一审决策 | 查看候选、通过/驳回一审 |
| **商品编辑** | 修订资料 | AI 生成、编辑、退回修改 |
| **上品审核员** | 二审决策 | 二审通过/退回/驳回 |
| **发布操作员** | 发起发布 | 发起发布、重试 |
| **只读验收** | 查看 | 仅查看，不修改 |

### 1.2 状态机

```
imported → normalized → filtered_out / scored → first_review → content_generating → editing → second_review → ready_to_publish → publishing → published
                                                       ↓ reject
                                                  rejected_1
                                                                  ↓ reject
                                                          rejected_2
```

## 2. 登录

1. 打开 `http://your-domain/`
2. 输入账号密码（默认 `admin/admin123`，6 个测试账号见 README）
3. 进入主页

## 3. 一审工作台（选品运营 / 上品审核员）

### 3.1 查看候选

进入"一审工作台"页面，默认显示今日待审核商品（按分数降序）。

每个商品卡片显示：
- **图片**、**标题、**分类、价格
- **总分**、**置信度**
- **进入详情 / 通过 / 驳回** 按钮

### 3.2 通过

- 单个商品：点击"通过"按钮
- 批量：勾选多个 → 点击"批量通过"

商品通过后会进入"资料生成"队列。

### 3.3 驳回

- 点击"驳回"按钮
- **必须填写原因**（原因必填）
- 常用原因：需求弱 / 竞争高 / 利润不足 / 侵权风险 / 物流不适配 / 资料不完整 / 重复商品 / 非目标类目 / 其他

驳回的商品状态变为 `rejected_1`，流程终止。

### 3.4 退回

- 点击"退回"按钮
- 填写原因
- 商品状态回到 `imported`，等待补充数据后重新评分

### 3.5 并发保护

- 同一商品被两个审核员同时点击时，**后点击的会被拒绝**（乐观锁）
- 提示"版本冲突：其他审核员已修改本页。请刷新后重试。"

## 4. 资料生成与编辑（商品编辑 / 上品审核员）

### 4.1 AI 生成

1. 进入"上品资料"列表，找到状态为 `editing` 的商品
2. 点击进入详情页
3. 点击"AI 生成"按钮
4. 等待 3-5 秒（mock 模式即时，真实 API 较慢）
5. 系统生成标题、卖点、描述

**AI 生成规则**（PRD FR-051）：
- AI 不会编造材质、规格、认证、功效、品牌授权、产地
- 数据缺失字段标记"待补充"
- 敏感词会被拒（best/100%/guaranteed 等）
- 标题 ≤ 200 字符

### 4.2 人工编辑

- 修改任何字段后点"保存修改"
- 每次保存版本号 +1
- AI 生成的字段会有 🤖 标记

### 4.3 版本对比与回退

- 右侧"版本历史"显示所有版本
- 点击"回退到此版本"可回退到历史版本（已冻结版本不可回退）
- 回退后版本号 +1，状态回到 `editing`

## 5. 二审（上品审核员）

### 5.1 进入二审

1. "上品资料"列表 → 状态为 `editing` 的商品
2. 点击"进入二审 →"

### 5.2 校验清单

二审页顶部显示校验结果：
- ✅ 必填字段、标题长度、图片 URL、类目匹配
- ⚠️ 警告（如缺少属性）：需勾选"我已知晓"才能通过

如果有 **错误**（红色 ❌），必须先退回编辑修复。

### 5.3 通过

- 校验全部通过 + 警告已确认 → 点击"通过 → 进入发布"
- 状态变为 `ready_to_publish`，生成**不可变快照**
- 后续任何字段变更都需重新二审

### 5.4 退回修改

- 点击"退回修改"
- 填写原因
- 状态回到 `editing`，快照清除

### 5.5 驳回

- 点击"驳回"
- 填写原因
- 状态变为 `rejected_2`，流程终止

### 5.6 同人校验

如果一审与二审是同一人：
- **建议模式**（默认）：允许，但系统记录"同人审核"事件
- **强制模式**：直接 403 拒绝

## 6. 发布（发布操作员）

### 6.1 发起发布

1. "上品资料"列表 → 状态为 `ready_to_publish` 的商品
2. 点击"发起发布 →"
3. 系统自动创建 job + 调用 Temu 适配器
4. 轮询显示进度

### 6.2 状态说明

| 状态 | 含义 |
|---|---|
| `pending` | 等待执行 |
| `submitted` | 已提交 Temu，等待异步结果 |
| `published` | 已发布 |
| `failed` | 失败（查看错误详情） |

### 6.3 错误分类

| 错误类 | 含义 | 处置 |
|---|---|---|
| `retryable` | 网络/超时/限流 | 自动重试 |
| `fatal` | 参数错误 | 退回编辑 |
| `need_auth` | 授权过期 | 联系管理员重新授权 |
| `need_fix` | 业务字段错误 | 修改字段后重试 |

### 6.4 手动重试 / 关闭

- 失败时点击"重试"
- 多次失败后可"关闭"（人工标记放弃）

## 7. 告警中心

### 7.1 查看告警

进入"告警中心"页面，自动轮询（10 秒）。

### 7.2 告警类型

- **error**：立即处理（如授权过期）
- **warning**：当天处理（如候选不足）
- **info**：了解即可（如测试告警）

### 7.3 手动测试告警

管理员可点击"发送测试告警"验证通知链路。

## 8. 评分配置（管理员 / 选品运营）

### 8.1 修改权重

进入"评分配置"页面，拖动滑块调整 6 维权重（总和必须 = 1.0）。

### 8.2 修改阈值

- 最低推荐分（默认 75）
- 类目占比上限（默认 40%）
- 每日推荐目标数（默认 20）

### 8.3 保存为新版本

点击"保存为新版本（草稿）"→ 草稿创建后点击"激活"。

### 8.4 回滚

历史版本可重新激活。

## 9. 数据源管理（管理员）

### 9.1 添加数据源

1. 进入 `/data-sources` 页面
2. 选择类型（CSV / XLSX / 内部 API / 第三方）
3. 填写配置

### 9.2 健康检查

点击"健康检查"验证数据源是否可用。

## 10. 类目字典（管理员）

### 10.1 导入字典

POST `/api/v1/categories/import` 上传 CSV 或 JSON。

CSV 列：`category_id, name, parent_id, attribute_key, attribute_type, enum_value`

### 10.2 搜索类目

POST `/api/v1/categories/search` 关键词搜索。

## 12. 常见问题 (FAQ)

**Q1：忘记密码怎么办？**
联系管理员重置，或直接在数据库中重置（参见 RUNBOOK）。

**Q2：为什么 AI 生成失败？**
查看告警中心 → 通常是 token 用完或敏感词拦截。可手动编辑。

**Q3：为什么二审按钮是灰的？**
- 您的角色无 `reviews.second` 权限
- 或 listing 已冻结（已通过二审）

**Q4：发布按钮按了没反应？**
- listing 状态不是 `ready_to_publish`
- 网络问题 — 查看告警中心

**Q5：如何查看某人改了什么？**
后端管理员可通过 `/api/v1/audit/events?entity_type=listing&entity_id=xxx` 查询事件流。

**Q6：评分模型改错了怎么回滚？**
`/scoring-config` → 选历史版本 → 激活。
